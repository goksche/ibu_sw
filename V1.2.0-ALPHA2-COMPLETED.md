## Testen Sie jetzt!

**Swagger UI:** http://localhost:8000/docs

### Test-Workflow

1. **User registrieren:**
   - `POST /api/v1/auth/register`
   - Body:
     ```json
     {
       "username": "admin",
       "email": "admin@example.com",
       "password": "secret123",
       "role": "admin"
     }
     ```

2. **Einloggen:**
   - `POST /api/v1/auth/login`
   - Body:
     ```json
     {
       "username": "admin",
       "password": "secret123"
     }
     ```
   - ✅ JWT Token erhalten

3. **Turnier erstellen:**
   - `POST /api/v1/tournaments`
   - Body:
     ```json
     {
       "name": "Test Turnier 2025",
       "description": "Ein Test-Turnier",
       "start_date": "2025-12-01",
       "mode": "combined",
       "has_group_phase": true,
       "has_ko_phase": true
     }
     ```

4. **Teilnehmer erstellen:**
   - `POST /api/v1/participants`
   - Body:
     ```json
     {
       "first_name": "Max",
       "last_name": "Mustermann",
       "club": "IBU Club",
       "email": "max@example.com"
     }
     ```

5. **Alle Turniere abrufen:**
   - `GET /api/v1/tournaments`
   - ✅ Liste aller Turniere

6. **Alle Teilnehmer abrufen:**
   - `GET /api/v1/participants`
   - ✅ Liste aller Teilnehmer
