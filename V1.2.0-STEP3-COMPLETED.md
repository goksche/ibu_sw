## Testen Sie jetzt!

**Swagger UI:** http://localhost:8000/docs

### Test-Workflow

1. **User registrieren:**
   - `POST /api/v1/auth/register`
   - Body:
     ```json
     {
       "username": "admin",
       "email": "admin@example.com",
       "password": "secret123",
       "role": "admin"
     }
     ```

2. **User einloggen:**
   - `POST /api/v1/auth/login`
   - Body:
     ```json
     {
       "username": "admin",
       "password": "secret123"
     }
     ```
   - Response: JWT Token erhalten
