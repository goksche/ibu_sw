- ✅ `backend/app/schemas/user.py`

### 7. Authentication API
- ✅ `backend/app/api/v1/auth.py`
  - `POST /api/v1/auth/register` - User Registration
  - `POST /api/v1/auth/login` - User Login (JWT Token)
  - `GET /api/v1/auth/me` - Current User (Placeholder)

## Neue API Endpoints

### 1. Register User
```
POST /api/v1/auth/register
Body: {
  "username": "admin",
  "email": "admin@example.com",
  "password": "secret123",
  "role": "admin"
}
Response: UserResponse
```

### 2. Login
```
POST /api/v1/auth/login
Body: {
  "username": "admin",
  "password": "secret123"
}
Response: {
  "access_token": "eyJ0eXAiOiJKV1QiLCJhbGc...",
  "token_type": "bearer"
}
```

### 3. Get Current User
```
GET /api/v1/auth/me
Headers: Authorization: Bearer {token}
Response: UserResponse
```
(Not yet fully implemented - needs token verification)

### Test-Workflow

1. Öffnen Sie: http://localhost:8000/docs
2. Testen Sie Registration:
   - Klicken Sie auf `POST /api/v1/auth/register`
   - Klicken Sie "Try it out"
   - Geben Sie ein:
     ```json
     {
       "username": "testuser",
       "email": "test@example.com",
       "password": "test123",
       "role": "user"
     }
     ```
   - Klicken Sie "Execute"
   - ✅ Erwartete Response: User-Informationen

3. Testen Sie Login:
   - Klicken Sie auf `POST /api/v1/auth/login`
   - Klicken Sie "Try it out"
   - Geben Sie ein:
     ```json
     {
       "username": "testuser",
       "password": "test123"
     }
     ```
   - Klicken Sie "Execute"
   - ✅ Erwartete Response: JWT Token
