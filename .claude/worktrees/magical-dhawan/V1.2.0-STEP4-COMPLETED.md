## Testen Sie jetzt!

**Swagger UI:** http://localhost:8000/docs

### Test-Workflow

1. **Turnier erstellen:**
   - `POST /api/v1/tournaments`
   - Body:
     ```json
     {
       "name": "Test Turnier 2025",
       "description": "Ein Test-Turnier",
       "start_date": "2025-12-01",
       "end_date": "2025-12-15",
       "mode": "combined",
       "has_group_phase": true,
       "has_ko_phase": true,
       "groups_count": 2,
       "ko_participants": 4
     }
     ```
   - ✅ Response: Turnier-Informationen mit ID

2. **Alle Turniere abrufen:**
   - `GET /api/v1/tournaments`
   - ✅ Response: Liste aller Turniere

3. **Turnier abrufen:**
   - `GET /api/v1/tournaments/{id}`
   - ✅ Response: Turnier Details

4. **Turnier aktualisieren:**
   - `PUT /api/v1/tournaments/{id}`
   - Body:
     ```json
     {
       "status": "running"
     }
     ```
   - ✅ Response: Aktualisierte Turnier-Daten

5. **Turnier löschen:**
   - `DELETE /api/v1/tournaments/{id}`
   - ✅ Response: 204 No Content
